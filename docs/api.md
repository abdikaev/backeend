# API Документация

Данное приложение использует REST API для взаимодействия фронтенда и бэкенда.
Ниже приведены основные эндпоинты платформы онлайн-курсов.

---

# 1. Аутентификация

## POST /api/register/
Регистрация нового пользователя.

### Тело запроса (JSON):
{
  "username": "user1",
  "email": "user@mail.com",
  "password": "12345"
}

### Ответ:
201 Created  
Пользователь создан.

---

## POST /api/login/
Авторизация пользователя.

### Тело запроса:
{
  "username": "user1",
  "password": "12345"
}

### Ответ:
200 OK  
Возвращает токен или сессию.

---

## POST /api/logout/
Выход пользователя из системы.

---

# 2. Курсы

## GET /api/courses/
Получить список всех курсов.

### Параметры:
- search= — поиск по названию  
- category= — фильтрация по категории  
- page= — пагинация  

---

## GET /api/courses/{id}/
Получить информацию об одном курсе.

### Ответ:
{
  "id": 1,
  "title": "Python Basics",
  "description": "Описание курса",
  "lessons_count": 10
}

---

## POST /api/courses/  (Только администратор)
Создать новый курс.

### Тело запроса:
{
  "title": "Новый курс",
  "description": "Описание"
}

---

# 3. Уроки

## GET /api/lessons/
Получить все уроки.

---

## GET /api/lessons/{id}/
Получить данные об одном уроке.

---

# 4. Категории

## GET /api/categories/
Получение списка категорий.

---

# 5. Поиск

## GET /api/courses?search=python
Поиск курса по ключевому слову.

---

# 6. Пагинация

Любой список поддерживает параметр:

?page=1  
?page=2  

---

# 7. Ошибки

## Пример ошибки валидации:
400 Bad Request
{
  "error": "Некорректные данные"
}

## Пример ошибки доступа:
403 Forbidden
{
  "error": "Недостаточно прав"
}

---

# Примечание
Фактические названия эндпоинтов могут отличаться в зависимости от вашей реализации.
Документация описывает общую структуру REST API платформы.
