# Руководство пользователя

Это руководство объясняет, как пользоваться платформой онлайн-курсов:
как зарегистрироваться, войти, смотреть курсы, проходить уроки и использовать админ-панель.

---

# 1. Регистрация

Для создания аккаунта:

1. Перейдите на страницу регистрации  
2. Введите имя пользователя, email и пароль  
3. Нажмите «Зарегистрироваться»

После этого вы сможете войти в систему.

---

# 2. Вход в аккаунт

Чтобы войти:

1. Откройте страницу авторизации  
2. Введите логин и пароль  
3. Нажмите «Войти»

При успешном входе вы будете перенаправлены на главную страницу.

---

# 3. Просмотр курсов

После входа:

- на главной странице отображается список всех доступных курсов
- каждый курс содержит:
  - название  
  - описание  
  - количество уроков  

Чтобы открыть курс — нажмите на него.

---

# 4. Просмотр уроков

Внутри курса:

- отображается список уроков  
- каждый урок можно открыть  
- урок содержит:
  - название  
  - видео/текст  
  - материал урока  

---

# 5. Поиск и фильтрация

На странице курсов можно:

- искать курсы по названию  
- фильтровать по категории  
- использовать пагинацию (страницы 1, 2, 3…)  

Примеры:

?search=python  
?category=3  
?page=2  

---

# 6. Личный кабинет (если реализован)

Пользователь может:

- просматривать свои данные  
- видеть прогресс (если добавлено)  

---

# 7. Админ-панель

Администратор может зайти в панель управления:

http://127.0.0.1:8000/admin

Админ может:

- добавлять курсы  
- редактировать курсы  
- удалять курсы  
- добавлять уроки  
- управлять пользователями  

Админ-панель доступна только суперпользователю, созданному командой:

python manage.py createsuperuser

---

# 8. Ошибки и ограничения

Если у пользователя недостаточно прав:

Вы увидите ошибку 403 Forbidden.

Если курс не найден:

Появится ошибка 404 Not Found.

---

# 9. Итог

Платформа позволяет:

- регистрироваться
- входить
- смотреть курсы
- проходить уроки
- пользоваться админкой
- искать и фильтровать курсы

Это базовый функционал онлайн-платформы обучения.
